# «بَلْ» — شفرة التطبيق

ألفاظ في القرآن الكريم والحديث الشريف تظن أنك تعرف معناها.

- التطبيق المنشور: https://bal-quran.ai.studio
- صفحة اختبار الحالات الحرجة: https://bal-quran.ai.studio/#/tests
- بُني التطبيق في Google AI Studio (Build)، وهذه شفرته كما هي.

## البنية

| المسار | المحتوى |
|---|---|
| `data/bal-data.ts` | الألفاظ والآيات والأحاديث والمصادر. مولَّد آلياً من `قائمة-الألفاظ-بل.xlsx` ومن نص مجمع الملك فهد (حفص، الإصدار 3.0)، ولا يُعدَّل يدوياً. |
| `data/critical-tests.ts` | الحالات الحرجة الخمسون، منقولة من `critical-tests.json` (الإصدار 2026-10-05). |
| `data/test-runs.ts` | التشغيل الموثق للحالات الخمسين (5 أكتوبر 2026). |
| `src/services/evaluate.ts` | منطق الحكم: القواعد الثابتة، ثم التصنيف الآلي. |
| `src/services/classifierShared.ts` | تعليمة المصنِّف وبناء الرسالة. |
| `src/services/storage.ts` | حفظ التقدّم والمراجعة المتباعدة في localStorage. |
| `server.ts` | الخادم: مسار `/api/classify`، وحد الطلبات، والذاكرة المؤقتة. |
| `src/App.tsx` | التنقل بين الصفحات، وفيه بطاقة اللفظ للتضمين (`#/card/ID`) وصفحة الدمج (`#/embed`). |
| `src/pages/` | الصفحات: الرئيسية، والرحلة، والألفاظ، واختبار الحالات، والمصادر. |

## التشغيل محلياً

1. ثبّت Node.js (الإصدار 22 أو أحدث).
2. ثبّت الحزم: `npm install`
3. انسخ `.env.example` إلى `.env`، واكتب فيه مفتاحاً واحداً على الأقل: `OPENROUTER_API_KEY` أو `GEMINI_API_KEY`.
4. شغّل: `npm run dev`، ثم افتح http://localhost:3000

## الأمان والخصوصية

- لا مفتاح في الشفرة. يقرأ الخادم المفاتيح من متغيرات البيئة، ولا يصل أي مفتاح إلى المتصفح.
- لا تسجيل دخول ولا بيانات شخصية. يُحفظ التقدّم في متصفح المستخدم وحده (localStorage).
- تُرسل إجابة المستخدم وحدها إلى النموذج لتصنيفها، مع بيانات اللفظ من القائمة.
